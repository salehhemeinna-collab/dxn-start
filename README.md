# DXN START 🇲🇷 — النسخة النهائية للمرحلة الأولى

## الهدف
نسخة أولى بسيطة وقابلة للاختبار، بدون إضافة أدوات خارجية جديدة.

## نموذج العضو الجديد
الحقول الموجودة في واجهة التسجيل:
1. الاسم الكامل / Nom complet
2. العمر / L’âge
3. رقم WhatsApp / Numéro WhatsApp
4. رقم عضوية DXN / Numéro de membre DXN
5. البريد الإلكتروني / Adresse e-mail
6. الهدف الأساسي / Objectif principal
7. الوقت المتاح بانتظام / Temps disponible régulièrement
8. ما الذي يريد تعلمه أولًا / Ce qu’il souhaite apprendre
9. الاستعداد للتطبيق / Prêt(e) à mettre en pratique
10. متى يستطيع البدء / Quand commencer
11. أفضل وقت للتواصل / Meilleur moment de contact

ملاحظة: سؤال الوقت تم تعديله ليقيس القدرة على التخصيص بانتظام، وليس فرض وقت قصير.
