DXN START - Rich Training Update

1. Replace the existing app.js in GitHub with app.js from this package.
2. Upload DXN_START_01.pdf to the repository root if you want the first PDF hosted with the site.
3. After the PDF is uploaded, set the first training pdf_url in Supabase to:
https://raw.githubusercontent.com/salehhemeinna-collab/dxn-start/main/DXN_START_01.pdf

The app.js update displays the rich training fields already stored in dxn_start_training:
content_ar, key_points_ar, action_ar, reflection_ar, source_note_ar, estimated_minutes.
It also adds these fields to the admin training editor.

Do not replace config.js or index.html with files from this package.
